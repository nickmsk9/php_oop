# php_oop

Учебный проект для изучения объектно-ориентированного программирования на PHP.
Примеры запускаются в терминале. Для начала достаточно PHP и Composer.

## Быстрый старт

Требования: PHP 8.2 или новее в пределах PHP 8, Composer 2.
На текущем компьютере установлен PHP 8.5.

В терминале PhpStorm, открытом в корне проекта:

```bash
composer install
composer start
```

Ожидаемый результат:

```text
Привет! Меня зовут Никита, я изучаю ООП на PHP.
Привет! Меня зовут Анна, я изучаю ООП на PHP.
```

## Структура

```text
src/                              Классы проекта, пространство имён App
examples/01-classes-and-objects.php Первый запускаемый пример
composer.json                     Требования, автозагрузка и команды
composer.lock                     Зафиксированные зависимости
.github/workflows/check.yml       Проверки на GitHub
```

Composer подключает классы по стандарту [PSR-4](https://getcomposer.org/doc/04-schema.md#psr-4):
класс `App\Student` находится в `src/Student.php`.
В каждом запускаемом примере один раз подключается `vendor/autoload.php`.
После клонирования проекта выполни `composer install`, чтобы создать `vendor`.

## Первое занятие

1. Открой `src/Student.php`: найди класс, свойство, конструктор и методы.
2. Открой `examples/01-classes-and-objects.php`: посмотри, как создаются два объекта.
3. Измени имена и снова выполни `composer start`.
4. Выполни задание в конце примера: добавь возраст через конструктор и метод `getAge()`.

Дальше можно двигаться по темам: инкапсуляция и проверка данных → наследование →
интерфейсы и полиморфизм → композиция → исключения → модульные тесты.
Новые классы добавляй в `src/`, а запускаемые задания — в `examples/`.
Например: `php examples/02-encapsulation.php` после создания такого файла.

## Проверки

```bash
composer lint    # Проверить синтаксис всех PHP-файлов в src и examples; macOS/Linux
composer check   # Проверить Composer, синтаксис и выполнить первый пример
```

На GitHub эти проверки запускаются при push и pull request на PHP 8.2 и 8.5.
Запуск примера проверяет работоспособность, но не заменяет модульные тесты.

## PhpStorm

- В Settings → PHP выбери локальный CLI Interpreter: `/opt/homebrew/bin/php`.
- Уровень языка можно оставить PHP 8.2: это минимальная версия проекта.
- В Settings → PHP → Composer выбери `/opt/homebrew/bin/composer`.
- Открой пример и запусти через контекстное меню Run либо командой `composer start` в терминале.
- `.editorconfig` задаёт UTF-8, LF и отступ в 4 пробела; настройки `.idea` остаются локальными.

## Сохранение прогресса

```bash
git status
git add src examples
git commit -m "Add age to Student"
git push
```

Перед коммитом проверь список изменений командой `git diff --cached`.
`vendor`, локальные настройки IDE, `.env` и логи исключены через `.gitignore`.
`composer.lock` хранится в репозитории; при добавлении зависимости обновляй его вместе с `composer.json`.
